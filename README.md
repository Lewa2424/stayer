# Stayer

Android-приложение для беговых тренировок с голосовым ведением, GPS-трекингом, историей и аналитикой.

## Что умеет

- Ведёт тренировку по GPS с резервным расчётом дистанции по шагам при проблемах с сигналом.
- Озвучивает подсказки по темпу и этапам тренировки.
- Сохраняет историю тренировок с деталями по участкам.
- Показывает аналитику по режимам.
- Содержит встроенный калькулятор темпа.

## Режимы тренировок

### 1. Обычная тренировка

Задаётся целевая дистанция и время или целевой темп.  
Приложение считает нужный график и каждые 10% дистанции озвучивает, нужно ли ускориться или замедлиться.

### 2. Интервальная тренировка

Сценарий с разминкой, рабочими интервалами, отдыхом, повторами и заминкой.  
Во время тренировки озвучиваются смены фаз, номер серии и обратный отсчёт перед переходом.

### 3. Комбинированная тренировка

Конструктор из блоков:

- разминка
- обычный темповый блок
- интервальный блок
- заминка

Блоки выполняются в заданном порядке и сохраняются в историю по сегментам.

### 4. Свободный бег

Простой режим без целевого времени и без сценария.  
Каждый километр озвучиваются:

- дистанция
- общее время
- средний темп за тренировку

### 5. Забег

Режим для соревнований и темпового плана по участкам.  
Задаётся общая дистанция и несколько участков с разными темпами.

Особенности:

- глобальные чекпоинты каждые 10% дистанции
- уведомление о переходе на новый участок
- ориентировочное опережение или отставание от плана
- история и аналитика по участкам забега

## Дополнительные инструменты

### Калькулятор темпа

Позволяет по любым двум параметрам вычислить третий:

- дистанция
- время
- темп

## История и аналитика

История сохраняет:

- общий итог тренировки
- сегменты для интервальных, комбинированных тренировок и забегов
- чекпоинты и отклонения там, где они доступны

Аналитика строится отдельно по режимам и показывает:

- суммарную дистанцию и время
- средние темпы
- лучшие и слабые участки
- отклонение от плана для режима `Забег`

## Основные файлы

- `app/src/main/java/com/example/stayer/WorkoutForegroundService.kt` — оркестратор активной тренировки
- `app/src/main/java/com/example/stayer/GoalActivity.kt` — настройка цели и режима
- `app/src/main/java/com/example/stayer/ui/main/MainScreen.kt` — главный экран
- `app/src/main/java/com/example/stayer/ui/main/InfoSheet.kt` — встроенная инструкция
- `app/src/main/java/com/example/stayer/WorkoutHistoryAdapter.kt` — отображение истории
- `app/src/main/java/com/example/stayer/analytics/WorkoutAnalyticsEngine.kt` — расчёт аналитики

## Новые модули

- `app/src/main/java/com/example/stayer/modes/free/` — логика режима `Свободный бег`
- `app/src/main/java/com/example/stayer/modes/race/` — логика режима `Забег`
- `app/src/main/java/com/example/stayer/calculator/` — модуль калькулятора темпа
